codex-remote is a TypeScript npm-workspaces monorepo for using Codex remotely from a phone. It has a mobile-first web frontend in apps/mobile-web, a Node HTTP gateway in apps/codex-gateway, and shared API/session types in packages/shared-types. The frontend uses React 19, TanStack Start/Router, Vite, Vitest, ESLint, Prettier, and Tailwind CSS. The gateway is a Node ESM TypeScript service using the built-in test runner and tsc for builds/linting. The gateway authenticates users with a shared password, lists projects under a configured root, creates or resumes Codex sessions, streams events, and proxies prompts, approvals, diffs, and terminal access.
